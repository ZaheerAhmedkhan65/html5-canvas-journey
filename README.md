# 🎮 HTML5 Canvas Journey

A growing collection of **mini projects for learning HTML5 Canvas** and vanilla JavaScript game-development techniques — from sprite animations to parallax scrolling — built step by step to gain real experience in creating amazing HTML5 games.

**🌐 View all projects:** [https://zaheerahmedkhan65.github.io/html5-canvas-journey/](https://zaheerahmedkhan65.github.io/html5-canvas-journey/)

---

## 🎯 Purpose of This Repo

This repository exists with one goal: **to learn the HTML5 Canvas API deeply and gain hands-on experience building HTML5 games.**

Instead of jumping straight into a big game engine or framework, each mini project here isolates **one core game technique** and implements it from scratch in pure vanilla JavaScript. This way, every canvas fundamental is genuinely understood — not hidden behind a library:

- 🖌️ **Rendering** — how the 2D context draws images, crops, and layers
- 🔄 **Animation** — game loops, `requestAnimationFrame`, frame staggering, delta timing
- 🎨 **Visual effects** — sprite sheets, parallax depth, particles, gradients
- 🕹️ **Interactivity** — keyboard/mouse input, sliders, and UI driving game state
- 🧱 **Architecture** — ES6 classes, data-driven design, and patterns that scale to full games

Every project ships with a README explaining the concepts, a code walkthrough, and a list of learning exercises. The long-term aim: stack enough of these fundamentals to confidently build **complete, polished HTML5 games**.

## 🚀 Getting Started

No build step, no dependencies — it's pure HTML/CSS/JS.

```bash
git clone git@github.com:ZaheerAhmedkhan65/html5-canvas-journey.git
cd html5-canvas-journey

# serve locally (recommended)
python3 -m http.server 8080
# then open http://localhost:8080 for the hub page
```

Or simply open any project's `index.html` directly in your browser. Each project folder contains its own `README.md` with a detailed breakdown of what it teaches.
